## 🎯 프로젝트 개요

Payment Service는 **안전한 결제 처리**와 **가상 지갑 관리**를 담당하는 서비스입니다.

### 핵심 기능
- **토스페이먼츠 연동**: 안전한 결제 처리
- **가상 지갑 관리**: 가상 지갑 잔액 관리
- **브랜드페이 연동**: 토스 브랜드페이 간편 결제 (추후 보완사항)
- **거래 내역 관리**: 상세 거래 기록 및 영수증
- **환불 처리**: 자동 환불 및 취소 처리

### 지원 결제 수단
- **카드 결제**: 신용카드, 체크카드
- **간편 결제**: 토스페이, 카카오페이, 페이코
- **브랜드페이**: 토스 브랜드페이

## 🛠️ 기술 스택

### Backend
- **Java 17** - LTS 버전
- **Spring Boot 3.5.0** - 최신 프레임워크
- **Spring Data JPA** - 데이터 액세스
- **QueryDSL 5.1** - 동적 쿼리 생성
- **Spring Security** - 보안 처리

### Database
- **MySQL 8.0** - 메인 데이터베이스
- **HikariCP** - 커넥션 풀

### Payment Gateway
- **Toss Payments API** - 결제 처리
- **Brandpay SDK** - 브랜드페이 연동

### Service Discovery
- **Netflix Eureka** - 서비스 등록/발견

### Documentation
- **SpringDoc OpenAPI 3** - API 문서화
- **Swagger UI** - API 테스트

## 🚀 주요 기능

### 1. 결제 처리
- **결제 요청**: 다양한 결제 수단 지원
- **결제 승인**: 실시간 결제 승인 처리
- **결제 취소**: 전액/부분 취소 처리
- **결제 실패**: 실패 사유 분석 및 재시도

### 2. 가상 지갑 관리
- **잔액 충전/사용**: 카드/계좌를 통한 충전
- **잔액 출금**: 계좌로 출금 처리

### 3. 거래 내역 관리
- **거래 기록**: 모든 거래 내역 저장
- **영수증 발행**: 전자 영수증 생성
- **거래 조회**: 기간별, 유형별 조회
- **거래 통계**: 월별, 연별 통계

## 💳 결제 프로세스

### 결제 흐름
1. **결제 요청**: 클라이언트에서 백엔드에 결제 요청
2. **정보 생성**: 결제 정보 생성 후 클라이언트에 전달
3. **결제 생성**: toss SDK를 이용해 toss에 결제 요청
5. **결제 검증**: 결제 요청 성공 후 프론트 redirect URL의 path variable들을 백엔드에 전송
6. **toss 외부 검증**: 백엔드-toss 간의 결제 검증
7. **완료 처리**: 결제 완료 및 알림

### 결제 단계 설명
- **검증 단계**: 결제 정보 및 사용자 정보 검증
- **승인 단계**: 외부 결제 게이트웨이를 통한 승인
- **완료 단계**: 결제 완료 후 후속 처리
- **실패 처리**: 결제 실패 시 롤백 및 알림

## ⚙️ 환경 설정

### 필수 요구사항
- Java 17 이상
- MySQL 8.0 이상
- Toss Payments API 키
- Docker (선택사항)

### 환경 변수
- **DATABASE_URL**: MySQL 데이터베이스 연결 정보
- **TOSS_PAYMENTS_CLIENT_KEY**: 토스페이먼츠 클라이언트 키
- **TOSS_PAYMENTS_SECRET_KEY**: 토스페이먼츠 시크릿 키
- **EUREKA_CLIENT_SERVICE_URL**: Eureka 서버 정보

### 주요 API 엔드포인트
